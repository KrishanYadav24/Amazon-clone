# Amazon Clone

A simple Amazon homepage clone built using HTML and CSS. This project recreates the basic layout and styling of Amazon’s landing page including the navigation bar, hero section, shopping cards, and footer.

---

## 🚀 Features

- Amazon-inspired navigation bar
- Search bar with category dropdown
- Hero section/banner
- Product category cards
- Footer section with links
- Hover effects
- Clean and organized layout

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome Icons

## ⚙️ Installation & Usage

1. Clone the repository

```bash

```

2. Open the project folder

```bash
cd amazon-clone
```

3. Run the project

Open `index.html` in your browser.
